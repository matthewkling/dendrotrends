# Source code for Kling et al. (2026) GCB

This repository contains analysis code (R and Stan) and results for the following journal article:

Kling, M., P. Burnham, M. Dube, B. McGill, B. McLaughlin, S. Miller, T. Waring, and N. Gotelli. (2026) Forest densification and pollution rival climate in driving US tree demographic change. Global Change Biology.

The project uses `targets`. To understand the workflow, start with `_targets.R`, which specificies the analysis pipeline calling functions defined within the `R` directory.
